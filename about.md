## About This Site

Built with **Vaporwave Theme** — a Jekyll theme channeling the aesthetic of 80s/90s retro computing, synthwave music visuals, and pastel vaporwave art.

### Design Highlights

- Synthwave perspective grid hero with animated scroll
- Pastel neon palette: hot pink `#ff71ce`, electric cyan `#01cdfe`, soft violet `#b967ff`
- Playfair Display serif headlines with gradient fill
- CRT scanlines overlay (pure CSS)
- Glitch hover effect on post titles
- Neon glow card borders
- Space Mono monospace for dates, tags, and code
- Zero JS dependencies for layout
